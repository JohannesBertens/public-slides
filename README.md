## Viewing the decks

The `.pptx` files are large (the current deck is ~165 MB) and stored with
[Git LFS](https://git-lfs.com). Install Git LFS **before** cloning, otherwise
you get small pointer files instead of the real slides:

```bash
git lfs install
git clone https://github.com/JohannesBertens/public-slides.git
```

Then open the deck in PowerPoint, Keynote, Google Slides, or LibreOffice Impress.
